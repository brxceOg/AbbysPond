# Abby's Pond

A cozy, romantic-cottagecore idle duck-collecting game made as a little gift for Abby. Designed mobile-first for iPhone Safari, with a living pixel-art-inspired pond, individual duck income, collection rolls, upgrades, keepsakes, automatic predator encounters, offline earnings, and hidden affectionate surprises.

## Play locally
Open `index.html` in a modern browser or serve this folder with any static web server. There is no build step or runtime dependency. The optional Google Fonts import is decorative; system fallbacks are included.

## How to play
- Tap the pond to make ripples; a little secret appears after several visits.
- Find a duck to spend pennies on a new duck roll.
- Pond upgrades improve income, luck, defense, roll cost, and offline earnings.
- Your flock menu lets you level individual ducks and equip compatible keepsakes.
- Keepsakes shows your inventory and discovered duck collection.
- Progress is saved in browser storage. Settings contains a confirmed reset-save action.
